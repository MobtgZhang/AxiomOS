# ADR-0001：先确定工程骨架，再逐条接通运行链路

状态：采用。

每个 Ada 包保留清晰的 `.ads` 接口和 `.adb` 实现；子系统按独立职责组合多个包。公共代码以 `AxiomOS` 为根包，架构 body 在构建时选定。避免单文件混合页分配、页表、堆与启动流程，也避免只有空目录或转发函数的形式拆分。

开发顺序：工程骨架与接口 → 可构建启动链路 → 四架构 UEFI 启动验证 → 内核公共算法与测试 → 各架构硬件机制。允许公共测试先行，但必须与实际硬件验收分开描述。

本轮不实现桌面、网络、音频、包管理，也不宣称通用硬件支持。

文件名遵循 GNAT 默认规则：包名转小写、点转连字符，声明 `.ads`、实现 `.adb`。保留 `AxiomOS` 根命名空间，避免无职责意义的额外层级；不为缩短显示名称维护自定义 GPR Naming 映射。
